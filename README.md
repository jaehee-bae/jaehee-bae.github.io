# jaehee-bae.github.io

Personal blog by **Jaehee Bae** — a Product Engineer who loves building things and writing about everything in between.

**Live:** [jaehee-bae.github.io](https://jaehee-bae.github.io)

## About

A place where I write about whatever I'm into — tech, products, ideas, and anything else that catches my attention. No strict topic, just things I find worth sharing.

## Tech

Built with [Jekyll](https://jekyllrb.com) using the [The Plain](https://github.com/heiswayi/the-plain) theme.

## Local Development

```bash
bundle exec jekyll serve
```

브라우저에서 `http://localhost:4000` 으로 접속하면 배포 전에 미리 확인할 수 있다.
